# Требования безопасности

| ID | Требование | Критерий приёмки | Связанные T / D (позднее) |
| --- | --- | --- | --- |
| SR-01 | Доступ к функционалу проекта доступен только авторизованным пользователям | При попытке обращения <ins>неавторизованного</ins> пользователя к системе через GUI выводится уведомление о необходимости авторизации; <br> При попытке обращения <ins>неавторизованного</ins> пользователя к системе путём подстановки GET-запроса выводится ошибка `HTTP 403 Forbidden`; <br> При попытке обращения <ins>авторизованного</ins> пользователя к системе открывается доступ к функционалу его роли | $-$ |
| SR-02 | Только системный администратор может изменять список устройств | Администратор может добавлять устройства, изменять их состояние и статус устройств; <br> Пользователи с ролями "Учитель" или "Ученик" могут только просматривать список устройств | $-$ |
| SR-03 | Действия авторизованных пользователей должны записываться в журнал аудита | Вход/выход, редактирование списка устройств и списка учеников, создание, удаление и рецензия заявок фиксируются в отдельной базе данных <br> Подозрительные действия пользователя, такие как: <br> многочисленные попытки входа в систему; <br> вход в систему и/или совершение любых действий после авторизации во внеучебное время <br> должны логироваться с пометками в виде предупреждений | $-$ |
| SR-04 | Система инвентаризации должна сохранять события при выдаче и возвращении устройств | Система должна сохранять данные журнала аудита как локально, так и на внешнем сервере; <br> В случае невозможности выгрузки на внешний сервер, система должна иметь журнал выполненных действий с момента последнего подключения к серверу | $-$ |
| SR-05 | Ученик может иметь только два устройства уникального типа | Ученик не может создать новую заявку, пока не сдаст одно устройство в систему инвентаризации | $-$ |
| SR-06 | Система должна работать только по защищённым каналам передачи | Функционал через API выполняется только по HTTPS; <br> Все HTTP-запросы отклоняются или перенаправляются | $-$ |
