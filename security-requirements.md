# Требования безопасности

| ID | Требование | Критерий приёмки | Связанные T / D (позднее) |
| --- | --- | --- | --- |
| SR-01 | Доступ к функционалу проекта доступен только авторизованным пользователям | При попытке обращения <ins>неавторизованного</ins> пользователя к системе через GUI выводится уведомление о необходимости авторизации; <br> При попытке обращения <ins>неавторизованного</ins> пользователя к системе путём подстановки GET-запроса выводится ошибка `HTTP 403 Forbidden`; <br> При попытке обращения <ins>авторизованного</ins> пользователя к системе открывается доступ к функционалу его роли | T-01, D-01 |
| SR-02 | Действия авторизованных пользователей должны записываться в журнал аудита | Вход/выход, редактирование списка устройств и списка учеников, создание, удаление и рецензия заявок фиксируются в отдельной базе данных <br> Подозрительные действия пользователя, такие как: <br> многочисленные попытки входа в систему; <br> вход в систему и/или совершение любых действий после авторизации во внеучебное время <br> должны логироваться с пометками в виде предупреждений | T-02 |
| SR-03 | Система инвентаризации должна сохранять события при выдаче и возвращении устройств | Система должна сохранять данные журнала аудита как локально, так и на внешнем сервере; <br> В случае невозможности выгрузки на внешний сервер, система должна иметь журнал выполненных действий с момента последнего подключения к серверу | T-03 |
| SR-04 | Система должна работать только по защищённым каналам передачи | Функционал через API выполняется только по HTTPS; <br> Все HTTP-запросы отклоняются или перенаправляются | T-04 |
| SR-05 | Только системный администратор может  добавлять/удалять аккаунты учеников и/или учителей | При попытке добавления или удаления ученика или учителя другими ролями, кроме администратора, выводится ошибка `HTTP 403 Forbidden`; <br> При попытке создания или удаления ученика администратором выводится уведомление для подтверждения в виде написания фразы "Подтверждаю" | T-05 |
| SR-06 | Только системный администратор может редактировать список устройств | Администратор может добавлять устройства, изменять их состояние и статус устройств; <br> Пользователи с ролями "Учитель" или "Ученик" могут только просматривать список устройств | T-06, D-01 |
| SR-07 | Только учитель может рецензировать заявки | При попытке рецензирования другими ролями, кроме учителя, выводится ошибка `HTTP 403 Forbidden`; <br> Учитель может одобрить или отклонить заявку ученика для получения последним доступа к устройству | T-07, D-01 |
| SR-08 | Ученик может иметь только два устройства уникального типа | Ученик не может создать новую заявку, пока не сдаст одно устройство в систему инвентаризации | T-08, D-02 |
| SR-09 | Ученик может просматривать исключительно свои заявки | При попытке посмотреть чужие заявки выводится ошибка `HTTP 403 Forbidden`; <br> При попытке посмотреть свои заявки ученику выводится список с историей заявок, их статусом, учителем, проводящим рецензию и вердикт | T-09, D-03 |
